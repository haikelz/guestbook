# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Visitors leave personal notes on guestbook.ekel.dev. Administrators review messages and contributor activity. The user confirmed both audiences are in scope.

## Product Purpose

Provide a personal guestbook for public conversation and an authenticated workspace for moderation.

## Capabilities and Constraints

Visitors sign in with GitHub or Google and publish messages. The public feed filters profanity. Administrators search messages and contributors, edit messages, and confirm destructive actions. Contributor management groups activity by email; it does not manage authentication accounts.

Keep Next.js Pages Router, HeroUI v3, existing authentication, tRPC contracts, real database content, and light/dark themes. Never fabricate live messages or activity statistics.

## Brand Commitments

Keep guestbook.ekel.dev, a blue primary informed by ReUI, and a modern, simple interface. The user authorized a complete visual redesign.

## Product Principles

- Make leaving a message straightforward.
- Put readable conversation before decoration.
- Make moderation outcomes and irreversible actions clear.
- Keep both public and admin surfaces usable on mobile.
